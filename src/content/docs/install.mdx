title: Install
description: Install @unitflow/core and @unitflow/react with their peer dependencies.
---

import { Tabs, TabItem } from "@astrojs/starlight/components";

For React apps, install the React package with its peers:

<Tabs>
  <TabItem label="pnpm">

```sh
pnpm add @unitflow/react @unitflow/core effect@4.0.0-rc.115 react
```

  </TabItem>
  <TabItem label="npm">

```sh
npm install @unitflow/react @unitflow/core effect@4.0.0-rc.115 react
```

  </TabItem>
  <TabItem label="yarn">

```sh
yarn add @unitflow/react @unitflow/core effect@4.0.0-rc.115 react
```

  </TabItem>
</Tabs>

For non-React runtimes, install the core package:

```sh
pnpm add @unitflow/core effect@4.0.0-rc.115
```

Packages:

- [`@unitflow/core`](https://www.npmjs.com/package/@unitflow/core)
- [`@unitflow/react`](https://www.npmjs.com/package/@unitflow/react)

`effect` is a peer dependency with the range `>=4.0.0-rc.115 <5.0.0`, so any
`4.0.0-rc.*` build from rc.115 onwards (and stable 4.x once it ships) satisfies
it. Install exactly one `effect` in your project: a second copy means a second
Effect runtime, and models silently stop making progress.

Continue with [Overview](./overview.mdx) for the core ideas, or jump straight
to [Stores](./store.md) to start writing model state.
